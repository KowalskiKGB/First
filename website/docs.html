Production deployment

The production stack builds the API and web images from the checked-out source:

git clone https://github.com/KowalskiKGB/First
cd First
cp .env.example .env
docker compose -f docker-compose.yml up -d --build

.env.example is prepared for https://first.rocketxsistemas.com.br. Review it before starting the service.

The base Compose file does not publish a host port. Attach your HTTPS reverse proxy to the Compose network (normally first_default) and route the public hostname to web:80. First does not publish prebuilt container images.

The complete production guide is docs/SELF_HOSTING.md.

Local preview

Copy .env.example to .env, then replace the production passkey origin with these local values:

RP_ID=localhost
ORIGIN=http://localhost:8080
VAPID_SUBJECT=mailto:admin@localhost
WEB_PORT=8080

Start the base file and local override together:

docker compose -f docker-compose.yml -f docker-compose.local.yml up -d --build

Open http://localhost:8080. The override binds to 127.0.0.1, so it is intentionally unavailable from other devices.

Passkeys and HTTPS

RP_ID must equal the hostname in ORIGIN. Browsers allow WebAuthn over HTTPS and, for development, over http://localhost. A plain LAN-IP URL is not a supported passkey origin. Changing RP_ID later invalidates passkeys registered for the old hostname.

Data and backups

The API writes profiles, public passkey records, sessions, Web Push keys, training state, and body-weight history under /data in the named volume first_first-data. The volume is not encrypted.

docker compose -f docker-compose.yml stop api
docker compose -f docker-compose.yml cp api:/data ./first-data-backup
docker compose -f docker-compose.yml start api

Protect and test that cold backup. Do not run docker compose down -v unless you intend to delete the persistent volume.

Exercise metadata and instructional text derived from hasaneyldrm/exercises-dataset retain its MIT license. Images and GIFs require a separate license from their copyright holder. First does not include, download, serve, or enable them by default.

Review NOTICE.md before preparing a separately licensed deployment.

Mobile builds

First includes inherited Capacitor source for local Android and iOS builds, but it does not publish a signed APK or iOS package. Build and signing instructions are in docs/MOBILE.md. The standard mobile build also leaves exercise images and GIFs disabled and absent.
