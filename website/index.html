First

Train on your terms. Keep the data.

An independent, self-hosted workout and body-weight tracker with passkey profiles, portable backups, and source you can inspect.

Open First Deploy from source View source

Current application

A training log that stays under your control

First keeps the proven workout flow from its openGym foundation while giving this independent version its own repository, deployment, and public origin.

Guided workouts

Run today's routine, prefill recent loads, time rests and work sets, and record personal bests.

Plans and progression

Build weekly routines and use the existing linear, Greyskull, double, timed, or body-weight rules.

Progress you can inspect

Track body weight, workout history, estimated 1RM, activity, and trained muscle groups.

Passkey profiles

Use WebAuthn instead of passwords and synchronize separate profiles through your own API.

Portable records

Export JSON backups, share plans, and import supported workout or body-weight exports.

PWA and mobile source

Install the web app or build the inherited Capacitor projects locally. No signed APK is published.

Source deployment

Two Compose files, two clear jobs

docker-compose.yml is the production stack. Add docker-compose.local.yml only when you need a loopback preview.

Production

For first.rocketxsistemas.com.br.

  • Copy and review .env.example
  • Build both images from this checkout
  • Keep data in the named Docker volume
  • Terminate HTTPS at your reverse proxy

Local preview

For http://localhost:8080.

  • Set RP_ID=localhost
  • Set ORIGIN=http://localhost:8080
  • Add the local Compose override
  • Use the loopback-only published port

Licensing boundary

Text is included. Exercise media is not.

Exercise metadata and instructional text derived from hasaneyldrm/exercises-dataset retain the upstream MIT license. Images and GIFs require separate permission from their copyright holder, so First does not include, fetch, serve, or enable them by default.

Open source

Independent repository, preserved obligations

First remains under the GNU AGPL v3.0. Modified versions used over a network must offer their corresponding source to those users. The original openGym attribution and third-party notices remain in the repository.
